# VYBE v4
Premium Android music player foundation.

## Included
- Jetpack Compose premium dark UI
- Home/search/liked/library navigation
- Media3/ExoPlayer playback
- Online stream-ready song model
- Device audio permission foundation
- Background/lock-screen architecture can be added with MediaSession

## Important
The demo online URL is only a placeholder stream. Replace it with a stream URL from a music provider that grants the required rights/API access. VYBE does not include Spotify/Apple Music copyrighted catalogues.

## Build
Open this project in Android Studio and build the debug APK. Minimum Android 8.0 (API 26), target SDK 35.
